# 打鍵戦線の基本ゲーム進行

部隊を編成し、ステージに出撃する。勝利で得た経験値を好きなキャラの育成に使い、次の攻略や再挑戦に進む。

| 手順 | 仕様 |
| --- | --- |
| 開始 | 起動・再読み込み時にユーザーを選択または作成する。新しいユーザーは初期キャラ5体を編成し、沖縄の拠点から出撃する。 |
| 編成 | 手持ちから最大5体を出撃枠に設定する。同じキャラは1枠までとし、空き枠を残せる。出撃には1体以上が必要。 |
| ステージ選択 | 挑戦可能なステージから選ぶ。攻略済みのステージにも何度でも挑戦できる。 |
| 出撃 | 選んだ編成と各キャラのレベルで戦う。タイピングで得た出撃コストを使って、編成内のキャラを自軍拠点から送り出す。 |
| 攻略完了 | 敵拠点のHPを0にすると勝利し、そのステージの設定経験値を得る。初回攻略では新キャラ1体が仲間になり、後続のステージがあれば次へ進める。再攻略でも同じ経験値を得る。 |
| 敗北 | 味方拠点のHPが0になると敗北する。手持ち、所持経験値、攻略状況を引き継ぎ、編成を調整して再挑戦できる。 |
| 育成 | 経験値は手持ち全体で共有する。キャラを選んで必要な経験値を使うと、そのキャラのレベルが1上がり、能力が強化される。 |
| 勲章 | 各拠点で制圧・精密・指揮の3個。「精密」は3語以上完了かつ正確率95%以上、「指揮」は1回以上発令して勝利。再攻略で追加取得できる。 |
| アメリカ戦線の解放 | 日本の全47拠点を制圧したユーザーはアメリカに出撃できる。仲間・編成・レベル・所持経験値を引き継ぐ。制圧記録と勲章は国ごとに保存する。 |
| 最終拠点 | ハワイ州まで全50州を制圧すると日米全97拠点の攻略が完了する。両戦線で再戦できる。 |

## ステージとバトル

- 日本編は47都道府県を各1ステージとする。各ステージに初登場キャラ1体、敵編成と各キャラのレベル、勝利時の経験値を設定する。敵味方は共通のキャラ図鑑を使う。
- 日本の最初の4ステージは敵の編成数を順に1〜4体とし、その後は既出キャラも含めて5体を編成する。日本の通常ステージは単タイプ中心で、各地方の最終ステージはボス戦となる。
- アメリカ編はメイン州からハワイ州まで50拠点。各州の初回攻略で日本編と重複しない門番が加入する。敵のレベルと経験値は日本編から通算した攻略順で決まる。
- 戦場はクオータービューの固定10レーン。会敵ラインで進軍を止め、射程内の相手に最もダメージを与えられる1タイプで自動攻撃する。拠点HP、戦場のキャラ、出撃コストは戦闘ごとに初期化し、編成・レベル・所持経験値・攻略状況は次の出撃に引き継ぐ。 [バトル仕様](battle-spec.md)
