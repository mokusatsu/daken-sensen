# 打鍵戦線の画面構成

[作戦本部](../index.html)から現在の前線へ直接出撃できる。戦区マップで別の拠点を選び、出撃前に部隊編成と敵の守備隊を確認できる。キャラ情報と育成は編成画面、戦闘結果は戦場のダイアログで扱う。 [基本ゲーム進行](game-lifecycle.md)

## にゃんこ大戦争の画面と導線

- **ネコ基地**からステージ選択、編成、パワーアップに移れる。**ステージ選択**にも編成への入口があり、攻略済みのステージではクリア時の編成を呼び出せる。ステージ名から出現する敵を見られ、初回挑戦前は「？」で表示される。 [ポノス公式ゲームガイド](https://ponosgames.com/information/appli/battlecats/help/index.html) · [ステージ選択の画面例](https://ponosgames.com/information/appli/battlecats/help/img/pict_050.png)
- **編成**で手持ちのキャラを出撃枠に入れ替え、**パワーアップ**で経験値を使って強化する。味方と敵の**図鑑**からキャラの説明を確認できる。 [ポノス公式ゲームガイド](https://ponosgames.com/information/appli/battlecats/help/index.html) · [編成の画面例](https://ponosgames.com/information/appli/battlecats/help/img/pict_027.png) · [にゃんこ図鑑の機能](https://ponosgames.com/information/appli/battlecats/zukan/index.html)
- **戦闘中**は貯まった所持金で出撃させるキャラを選び、ポーズから離脱できる。クリアで経験値を受け取り、ステージ選択へ戻るボタンがある。 [ポノス公式ゲームガイド](https://ponosgames.com/information/appli/battlecats/help/index.html) · [ポノス作品紹介](https://www.ponos.jp/games/thebattlecats/) · [ポノス更新案内](https://ponosgames.com/information/appli/battlecats/event/20190218.html)
- **タイトル**からゲームを始め、進行に応じてイベントステージなども選べる。**オプション**にはBGM・効果音の調整とヘルプがある。 [ポノス公式FAQ](https://ponosgames.com/information/appli/battlecats/faq/qa.html) · [ポノス公式ゲームガイド](https://ponosgames.com/information/appli/battlecats/help/index.html)

## 打鍵戦線で必要な画面

| 画面 | 表示と操作 | ゲーム内の機能 |
| --- | --- | --- |
| ユーザー選択 | 起動・再読み込み時に、名前と制圧数を見てユーザーを選ぶ。新規作成も同じ画面で行う。 | 作戦本部と戦区マップのヘッダー、戦闘中の「戦況・設定」から開ける。別のユーザーに交代すると、そのユーザーの作戦本部に戻る。 |
| 作戦本部 | 現在の攻略目標、出撃部隊、戦績と所持経験値を表示する。 | 前線への出撃、日替わり演習、編成・育成、戦区マップ、図鑑、遊び方、音量設定を開ける。 |
| 戦区マップ | 作戦本部と同じヘッダーと戦線切替を使う。左に地図、右に選んだ拠点の風景・守備隊・報酬と出撃ボタンを表示する。 | 日本47拠点の制圧でアメリカ50州が開く。地図で挑戦可能・攻略済み・未解放を見分け、拠点ごとの勲章を確認できる。 [日本マップ](../preview/japan-stage-map.html)・[アメリカマップ](../preview/usa-stage-map.html) |
| ステージ情報／出撃（マップ内） | 地図の拠点と選択リストに、地名と敵の平均Lvを表示する。選択中の拠点では敵1体ごとのLv・タイプ・役割、地方ボス、経験値、加入するキャラを確認できる。 | 編成を変更し、選んだ拠点に出撃できる。作戦本部から直接出撃するときも攻略目標に敵の平均Lvを表示する。 |
| 部隊編成 | 手持ちから最大5体を入れ替える。キャラの役割・タイプ・Lvを見比べる。1体以上で出撃できる。 | 初期5体と攻略で加入したキャラを編成できる。 [編成デモ](../preview/formation-demo.html) |
| 情報/育成（編成内） | モデルを回して確認する。所持経験値、強化に必要な経験値、強化前後の能力を確認してレベルアップする。 | 経験値を使うと体力と一撃の威力が上がり、バトルに反映される。 |
| タイピング戦闘 | 3カウントで開始する。お題、ローマ字ガイド、指揮ゲージ、両拠点のHPと再出撃までの時間を表示する。 | 実キーと画面キーで入力し、カードやShiftキーの組み合わせで召喚できる。総攻撃・補給の号令とオート召喚の切り替えに対応する。 |
| ポーズ（戦闘内） | 戦闘を止めて再開できる。 | バトル上部の一時停止ボタンを使う。 |
| 仲間の加入 | 初めて仲間を獲得すると、専用ファンファーレとともに登場し、本人の攻撃モーション、名前、タイプ、役割を表示する。 | 「この仲間を編成」で加入したキャラを選択した編成画面、「戦果を見る」で戦闘結果を開く。 |
| 戦闘結果（戦闘内） | 勝敗、拠点HP、戦闘時間、正確率、打鍵速度、勲章を表示する。 | 初回制圧・再制圧の経験値や加入した仲間を確認し、次の拠点・再戦・編成を選べる。 |
| 初回ガイド（マップ・戦闘内） | 最初の拠点で初期の手持ち5体と出撃手順を案内する。初戦で、入力と号令の使い方を示す。 | マップの「初回ガイド」と戦場の「操作」から開き直せる。 |
| 共通図鑑・相性表 | 敵味方で同じキャラ情報を開ける。タイプや役割で探し、手持ちと対戦済みのキャラを見分けられるようにする。 | 200体をページ送りで表示する。キャラの回転・静止・歩行・攻撃、18タイプの相性表と倍率計算を使える。 [キャラクター図鑑](../preview/character-roster.html) |

## 結果からの行き先

| 結果 | 進行に反映する内容 | 次の操作 |
| --- | --- | --- |
| 初回攻略 | 県を攻略済みにし、設定された経験値と新キャラ1体を獲得。後続の県があれば挑戦可能にする。 | 次の県へ・編成／育成・地図へ |
| 再攻略 | 同じステージ経験値を獲得。 | 同じ県に再挑戦・編成／育成・地図へ |
| 敗北 | 手持ち、経験値、攻略状況を引き継ぐ。 | 同じ編成で再挑戦・編成を見直す・地図へ |

マップから編成や図鑑を開いて戻ったときは、選んだ県と地図の位置を維持する。敗北後に編成を見直したときも同じ県に戻る。

## 共通レイアウト

レイアウトの設計・検証対象はPCと横向きのタブレット。スマートフォン専用レイアウトは対象外とする。主画面とダイアログは主要操作が1画面に収まるようにし、PCの横長画面と、iPad Air第5世代相当の1180×820 CSS px、表示領域を縮めた1180×600 CSS pxで確認する。編成と図鑑の一覧はページ送りを使い、相性表や能力の比較は表示する項目を切り替える。 [Appleの技術仕様](https://support.apple.com/ja-jp/111887)
